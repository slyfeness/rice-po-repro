pytest 的实际加载版本字符串未单独写入运行报告，不补造精确版本。本次公开清单保留这一缺口。CPU 环境清单中的节点 GPU 可见数不等于 Slurm 分配数，不据此宣称使用八卡或通过四卡验证。

`preparation._publish` 原路径在共享挂载点报 EINVAL；修复后的历史 CPU 测试覆盖既有目标拒绝、失败发布与重试。依赖所有发布方遵守同一 sibling flock 协议和文件系统正确实现锁与原子 rename。未执行双作业、跨节点或断电实验。
