# 两阶段协议：真实信用更新已打通，开发性能未达标

本轮首次让真实反事实局部信用参与 RICE-PO 在线更新：4 条固定训练查询、16 条原始轨迹、16 个熵锚点、80 条新分支。9/16 锚点可估计，4 个局部优势非零，实际改变 1,070 个 token 的优势。PPO 完成一次有限梯度更新，完整权重变化；RICE 与 GRPO 检查点均已在独立 Slurm 进程恢复模型、优化器和 CPU/CUDA 随机状态。开发性能下降，不能称为论文性能复现。

[论文 v3](https://arxiv.org/html/2605.26352v3) · [公开仓库](https://github.com/slyfeness/rice-po-repro) · [现有 PR #2](https://github.com/slyfeness/rice-po-repro/pull/2)

## 固定训练查询的协议对照

同一固定八题、轮次种子、初始权重、预填充兼容提示和检索器；Actor 均为 FP32。历史 BF16 的 0/8 不作为匹配对照。

| 方案 | 实际动作请求 | 合法检索动作 | 完整五轮 |
|---|---:|---:|---:|
| A：原生成方式 | 23 | 16 | 1/8 |
| B：two_stage_env_summary_v1 | 31 | 27 | 4/8 |

B 的 31 次动作均采样到 Think 关闭标记，其中一次 Think 结构非法未进入 Summary；实际进入 Summary 30 次，27 次得到合法正文。本组 27 次均实际采样了关闭标签，未出现以 EOS 合法结束的 Summary；EOS 分支另有明确 CPU 测试。A 有一次 EOS 早于 Think 关闭。逐轮分母区分已终止后不再请求的情况，不虚构后续五轮。

B 中断于一次真实无效 UTF-8：完整原生 Summary 字节不能与替换字符解码精确对应。只拒绝该动作，保留所有 IDs/概率/种子，按既定非法终态计效用 0；没有新增标签修补规则。恢复精确复用 17 个已付费动作，重新执行的确定性检索和新增生成分别计费；旧文件未改写。该恢复是协议诊断，在线训练是独立新采样。

## 原生结构与概率

`前缀/预填充(False) → sampled Think + </think>(True) → 环境 <summary>(False) → sampled Summary + 关闭标签或 EOS(True) → 工具/角色边界(False)`。

每轮两个阶段共享一个 RNG 流，共用 4096 个模型 token 预算。环境控制计入上下文，不计入模型动作预算。原始 IDs 不重编码；正文使用已有 ByteLevel 原生跨度规则。严格 Figure 5 路径保留。两阶段协议和既有失败效用 0 均为独立环境约定，未经作者确认，会改变轨迹条件历史。

采样 logits 观察器原样返回同一个张量，只保存采样 token 的完整词表条件 log-prob。新模式 PPO 分母用实际捕获值；完整原生历史 teacher-forcing 另作数值检查。初始 BF16 和 BF16+FP32 head 均未通过预先声明的门限，没有放宽阈值。FP32 Actor 的短条件最大误差约 2e-5 nats，Diver 仍保持原 BF16 和索引身份。

本次 16 条原轨迹、25,768 个动作 token 的完整历史检查：加权平均误差 6.0595405e-06、最大逐轨迹 p99 3.6716461e-05、全体最大误差 7.9631805e-05 nats。p99 是逐轨迹统计的最大值，不冒充全批次重算分位数。更新前实际 ratio 范围 0.999924660～1.000079632，没有将打印的 1 当成精确相等。

## 真实反事实信用与梯度

原始轨迹 7/16 正常到达第五轮，其余 9 条非法终止，全部保留。80 条新分支中 47 条正常到达共同第五轮终点，33 条非法终止；71/80 在锚点处产生合法检索。9/16 锚点的六个局部结果齐全，其余 7 个整组 not_estimable，不以成功分支缩小分母。原分支各统计一次；新分支不进入优化批次。

9 个可估计锚点都未同时通过 0.05/0.03 门控，故没有给推理赋局部优势；它们保留轨迹优势，上下文梯度正常计算。末轮锚点的残差为零是定义结果，不额外声称未来稳定性。非零局部锚点激活率为 4/16，实际改变动作优势 1070/25,768；多数 token 仍采用轨迹优势。

两方法的首批 16 条原始 IDs、mask、奖励和行为策略身份逐条相同。同批原始数据的额外 GRPO 梯度诊断不调用 optimizer.step；实际 RICE 更新结果：

- GRPO 梯度 L2 1195.313754，RICE 1146.472287，梯度差 295.757945，余弦 0.968955。
- 一次真实 RICE optimizer.step；参数变化 L2 0.037242226，梯度与实际参数位移内积 -16.706591，一阶方向下降。
- 参考模型无梯度；初始条件 KL 为 0，clip 激活率为 0。单次参考更新下 clip 为 0 合法，不作为失败。
- LR=1e-6、KL 系数=0.001、ppo_epochs=1、整批16轨迹、微批1、累积16、sequence_mean（逐序列 token 损失求和再平均）、clip=0.2、max_grad_norm=1 均保持冻结选择。

这证明局部信用影响真实更新，不证明新策略期望检索回报增加；开发结果已经显示本次性能下降。

当前对照固定原始查询、轨迹和一次优化预算，并非等计算预算；RICE 的额外分支与诊断反向成本全部披露。

## 检查点、加速和成本

同规模 IO 测试实际写入并加载 21,325,384,127 字节。生产检查点先在自有本地临时目录关闭/重载，核对实际模型和完整优化器/RNG，再复制共享暂存、逐文件校验、原子发布。两种方法的实跑检查点都已独立进程完整恢复，优化器 step=1；恢复检查新 step=0。旧损坏资产保留，未宣称已定位或修复共享存储根因。恢复 IO 仍较慢。

HF 短序列串行/批量各 512 token 实测 45.51/161.12 token/s，约 3.54 倍；这是短条件吞吐，不是完整训练提速。另用身份预定的四条真实训练前缀实际生成两阶段：4/4 合法 Summary，1,806 token /14.857 秒，约121.56 token/s，最大概率误差 5.7e-5 nats。顺序置换不改变固定请求 IDs；加载真正已变更权重后也重新通过概率检查。批量候选尚未接入在线 Trainer；本次训练串行，vLLM 和四卡 FSDP 未验证。

并行峰值为 4 GPU：RICE/GRPO 两个独立双卡作业；空余资源用于独立恢复、单模型批量核验和初始评估。不是单任务四卡分布式训练。本阶段全部失败初始化、数值诊断、恢复及评估均计费：**6.616111 GPU小时**；累计 **10.791666/32**，剩余 **21.208334**。本阶段真实生成总计 339,881 token，包含失败和诊断；RICE 新续跑 100,841 token、172 次新合法检索，复用历史不计作新生成。

实际主作业时长：RICE 1:31:35，GRPO 0:47:26；两者包含初始化、IO、评估。RICE 还含同批 GRPO 梯度诊断的额外反向传播，不能将它当生产算法固有更新开销。分类 host wall 为嵌套计时，不能直接相加；实际 GPU 利用率/FLOPs未完整采样，分配时长不等于 GPU 一直忙。
