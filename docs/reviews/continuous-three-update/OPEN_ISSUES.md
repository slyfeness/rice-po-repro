# Remaining conditions before paper-scale work

1. **Performance, not just execution.** This is one seed, one domain, four training queries per update and only three updates. A nonzero policy objective and changed weights do not establish improved retrieval. Use the complete32 development comparison in `SUMMARY.md`; do not tune a prompt, seed, reward or gate to that set. Multiple fixed seeds, an independently fixed longer training budget and official test selection remain future work.
2. **Independent protocol/environment.** Two-stage environment-controlled Summary opening, compatibility prompt, native unmapped-ID failure handling and illegal-terminal utility zero are not confirmed author settings. Retain their labels. Genuine retrieval NDCG, last-valid NDCG, conditional completion mean and failure-adjusted utility remain separate. Strict Figure5 reference path is preserved but not validated as a reliable five-round training protocol.
3. **Interpret credit carefully.** `not_estimable` anchors retain trajectory advantage. Some nonzero local replacements can occur without reasoning propagation. At depth5 the residual is zero by definition: a gate pass there is not evidence that future reward is stable. Inspect nonterminal gates separately. Single sampled paths do not identify which wording change was caused by local credit.
4. **Batch acceleration scope.** The optional Trainer sampling path is wired and the actual long-history workload/probabilities have been checked. Full batched online optimizer/checkpoint/development execution with co-resident reference is not run in this frozen serial comparison. Measured long-workload gain is modest, and the weight-switch test includes a slowdown case. Maximum tested lengths are reported; no 32K worst-case or all-workload equivalence guarantee follows. vLLM IEEE conditional-history sampling passed80 actual checks, but its native two-stage/weight-sync/Trainer path and four-rank FSDP remain unqualified.
5. **Storage and recovery limits.** Complete checkpoints were independently reloaded. The source of earlier shared-storage corruption is not claimed fixed. Local verified staging and atomic publication reduce exposure but require measured I/O budget. Continuation currently accepts a completed one-update parent. General multi-generation lineage/test selection and interrupted-optimizer recovery remain unsupported; formal test on a continuation explicitly rejects. Never repoint another config at an existing output directory.
6. **Recovery evidence gap.** The first failed callback lost its partial Summary IDs. Saved complete actions are verified; the one same-seed native replay is disclosed separately. The missing original evidence cannot be reconstructed as a historical fact. Original failed allocation cost is retained, and its missing token cost is a lower bound, not zero.
7. **Assets and scale.** Current bundle is Biology-only 128/32/103, not complete BRIGHT twelve-domain or author-identical ReasonIR training membership. Author code and unspecified choices remain unavailable. Additional domains, full paper batch128 resource checks and formal budget need explicit later authorization; they are not auto-started using leftover GPU hours.

The two methods keep independent optimizer/model state with the same frozen query schedule and sampling specification. At later updates their actual behavior policies differ, so equal seeds need not produce equal trajectories. The native-unmapped failure handler is a recorded source difference after the original RICE crash; this is a limitation of the continuation comparison, not a hidden claim of identical executed source trees. The handler does not mask probabilities or alter valid-action rewards.
