# Native-action recovery, separate from checkpoint continuation

The first RICE continuation (Slurm 174715, immutable source `e70e6b2`) stopped before its first new optimizer step. It had completed all 16 originals, entropy selection and 49 new branches. During the next Summary generation, the tokenizer returned `None` for an actually sampled output ID; the old stopping callback tried to convert that value into bytes. This was not another tag-boundary ambiguity. CPU inspection of the frozen assets found model output vocabulary 151936 versus tokenizer IDs through 151664, leaving 271 model rows without a tokenizer token representation.

`UnrepresentableNativeToken` and the independent two-stage adapter now recognize this condition after sampling. No logits are masked, no model is resized, and no token is removed or re-encoded. The sampled ID, its probability and action mask remain in the invalid action. Under the already registered `invalid_action_terminal_zero_v1` environment, inability to represent a valid Summary terminates that trajectory with training utility zero; its last measured NDCG remains a separate field. It produces no invented Summary or retrieval. The paper-strict parser is unchanged. This extends failure handling from an engineering crash to an explicit illegal terminal action; it is an implementation convention, not an author-confirmed failure rule.

The failed callback did not save the partial Summary IDs. They are **unavailable in the original failed attempt**. The recovered run does not claim otherwise. The original failure, cost lower bound, completed traces and checkpoints remain untouched.

`VerifiedActionRecovery` admits just one failed source that has no committed optimizer step. It checks configuration, recipe, assets, parent lineage, actual behavior policy and immutable source fingerprints. Each cache entry is keyed by policy, seed and original prefix. It reuses 177 complete native action records from 178 paid requests. All 16 original trajectories, 49 completed branches and selected anchors are checked against their saved IDs, masks, spans, rewards and rankings before credit. Deterministic retrieval is rerun and its cost is counted.

For the one unavailable partial Summary, the saved Think stage is mandatory. The same policy, prefix, seed and RNG progression are re-executed; saved Think IDs and probabilities must match before accepting the replay, and the original failure cause must recur. This is an infrastructure recovery replay, not a new independent branch or a successful resample. In Slurm 174747 it reproduced an unrepresentable final ID 151800, retaining 90 actually generated model tokens and their sampled probabilities. The new evidence records both that replay and the missing original partial evidence.

The recovery run has a fresh output directory, immutable source `534b853`, and the same update-one checkpoint, global schedule, original sampling law and scientific configuration. Update two is explicitly recovery-backed; update three is newly generated online from update two's actual trained weights. No committed optimizer step is repeated, and incomplete branch groups never enter formal credit. Five new branches per selected anchor are retained, including terminal failures. Missing anchor-local rewards yield `not_estimable`, rather than invented local NDCG.

Targeted CPU tests (174746) cover admission, altered source/behavior/recipe, mandatory saved Think, native unmapped IDs and unchanged strict parsing. Real replay and subsequent credit/update evidence are in `EVIDENCE.json`. Raw traces and the original private exception log are not public.
